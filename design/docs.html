Pages & frontmatter

Every file in pages/ becomes one HTML page. A page is plain Markdown with a YAML frontmatter block that tells Nera how to render it.

YAML frontmatter

Frontmatter sits between two --- lines at the top of the file. Everything you declare there is available to your Pug template as meta.

Common keys — none are required, but layout falls back to the default template:

keytypepurpose
titlestringPage title, used in <title> and nav
layoutstringPug template rendered around the content
descriptionstringMeta description for search engines
createdAtdateUsed by list, tag and RSS plugins

Tip — any custom key you add is passed through untouched. Plugins and templates can read it from meta.customKey.

Where pages end up

The folder structure of pages/ maps one-to-one onto your site's URLs — pages/blog/hello.md becomes /blog/hello/index.html in public/.
