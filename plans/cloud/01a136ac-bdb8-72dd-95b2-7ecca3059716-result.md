## Decisions

- Section layout: five `## ` sections (install; origin incl. `base_path`; emit
  tags/include; hreflang; plugin order) plus unheaded closing paragraphs for
  plugin-sitemap and this site, like the closing of the tag tutorial. `base_path`
  sits in the origin section because it composes the same URL.
- The old section "3. Give pages a slug" was folded into the hreflang section:
  the slug does not shape the canonical URL (the page path does), it only matches
  translations — the old text implied otherwise.
- The brief expected "canonical + two hreflang alternates on each" page; the real
  2.2.3 output is canonical + **one** alternate (the other language; the plugin
  never emits a self-referencing alternate). The tutorial shows the real output
  and says "Each page points at its translations, not at itself".
- This site's Spanish pages: they do get `en`/`de` alternates (es is not in
  `available_languages`, but the lookup runs for every listed language other than
  the page's own); what is missing is any `hreflang="es"`. The closing note says
  exactly that rather than "Spanish pages get no alternates".
- Stamp: `plugin-canonical-links: 2.2.3` and `plugin-sitemap: 1.0.1` (the text
  claims sitemap behaviour, verified in the throwaway site with base_path). No
  `nera`/`core` stamp: the only core claims are version floors (4.2.0 for
  plugin-order, 4.1–4.2 for the relative include) taken from the README.
- The `end:` snippet in the tutorial lists only `plugin-canonical-links` (what was
  built and verified); the site's own extra `plugin-search` entry is mentioned
  only as "puts plugin-canonical-links under `end:`".
- Code blocks are byte-identical in all three languages, including the German
  example frontmatter (`Erste Schritte`) and the English warning text.
- Frontmatter `description`/`keywords` extended (subdirectory sites, generated
  pages, `base_path`) in all three, since the old description no longer covered
  the page.
- Commit trailer: used the brief's `Co-Authored-By: Claude <noreply@anthropic.com>`.
