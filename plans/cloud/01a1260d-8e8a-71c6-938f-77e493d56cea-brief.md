## Facts you may state on the page (the current truth, 2026-10-12)

Only state what is true today. When unsure whether something exists, check it
(see "Verify claims" below) or leave it out.

**Available now:**

- Every site created with `npx @nera-static/nera new <name>` (since
  `@nera-static/nera` 1.6.0) contains **`AGENTS.md`** and **`CLAUDE.md`**.
  `AGENTS.md` is the cross-tool instruction file read by Codex, Cursor, GitHub
  Copilot, Gemini CLI and others. `CLAUDE.md` holds one line, `@AGENTS.md`, so
  Claude Code loads the same text.
- `AGENTS.md` covers: what Nera is (and that it is not Eleventy/Hugo/Astro/
  Jekyll), links to the docs and to `llms.txt`/`llms-full.txt`, the folder map
  (`pages/`, `theme/views/`, `theme/assets/`, `config/`, `src/plugins/`,
  `public/` = generated, never edit), the commands (`npm run dev`,
  `npm run build`, `npx nera validate`, `npx nera build --check`,
  `npx nera check`), "after every change run `nera validate`, then
  `nera build --check`", the traps (a page needs `layout` or it is silently
  skipped; URLs end in `.html`; `public/` is wiped on every build; site files
  override theme files; translations via `t('key')`), plugins (look in the
  catalog before writing a feature; `@nera-static/plugin-contact-form`,
  `@nera-static/plugin-navigation`; plugin templates are copied with the
  plugin's command and included by hand).
- The end of `AGENTS.md` is a section **"Notes for this site"** below a marker
  comment. It belongs to the site owner: audience, tone, languages, pages that
  must not change, hosting. Everything above the marker belongs to Nera.
- **Existing sites:** `nera update` (since `@nera-static/nera` 1.7.0) creates
  `AGENTS.md` and `CLAUDE.md` when they are missing, and refreshes only the part
  above the marker when `AGENTS.md` exists, so the user's notes survive. An
  `AGENTS.md` without the marker is treated as the user's own and left alone.
  Check `pages/docs/cli.md` for how the docs already describe `nera update` and
  match it.
- **Docs for AI on nera.js.org (English only):**
  `https://nera.js.org/llms.txt` (index of the docs per the llms.txt
  convention), `https://nera.js.org/llms-full.txt` (all English docs and
  tutorials in one Markdown file), and a raw Markdown file next to every English
  docs and tutorials page (`https://nera.js.org/docs/cli.md` beside
  `/docs/cli.html`). They are English only on purpose: models read English docs
  well and answer in the user's language. On the German and Spanish page, say
  so in one sentence.
- Chat assistants without access to the user's files (claude.ai, ChatGPT and the
  like) do not see `AGENTS.md`; point them at `llms.txt` / `llms-full.txt` or a
  page's `.md` URL in the prompt.
- The workflow to recommend: ask for a change → let the agent edit → it runs
  `npx nera validate` and `npx nera build --check` and fixes what they report →
  preview with `npm run dev` → review the diff (git) before publishing.
